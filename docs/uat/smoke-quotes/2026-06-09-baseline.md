## Engineer helper — `scripts/cutover/dump-baseline-numbers.mjs`

After saving a quote in v1.5.10, dump the 11-field baseline in
paste-ready markdown via:

```bash
# List recent quotes (pick the one you just saved)
node scripts/cutover/dump-baseline-numbers.mjs --list --type std
node scripts/cutover/dump-baseline-numbers.mjs --list --type cpx

# Dump one quote's baseline block (paste under "v1.5.10 actual outputs")
node scripts/cutover/dump-baseline-numbers.mjs <quote_id>
```

Defaults to the Mac DMG embedded server DB at
`~/Library/Application Support/ops-control-desktop/data/ops.db`.
Pass `--db <path>` or set `OPS_DATA_DIR` for the standalone-server
path (e.g. `./server/data/ops.db`) or remote-pulled snapshots.

Read-only — safe to run while the server is serving traffic.
